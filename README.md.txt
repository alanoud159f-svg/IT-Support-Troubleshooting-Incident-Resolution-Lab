# IT Support Troubleshooting & Incident Resolution Lab

## Practical IT Support Home Lab

**Prepared by:** Alanoud Alfouzan

### Project Overview
A practical IT Support home lab focused on troubleshooting and resolving common technical incidents using a Kali Linux virtual environment.

### Incidents Covered
- Network connectivity troubleshooting
- DNS resolution verification
- System performance analysis
- Application process management
- Disk space analysis
- Linux file permissions
- Network services and listening ports
- SSH configuration verification

### Tools Used
- Kali Linux
- Oracle VM VirtualBox
- Linux Terminal
- `ip`, `ping`, `ss`, `ps`, `top`, `free`, `df`, `du`
- `chmod`, `stat`, `systemctl`

### Skills Demonstrated
- Network troubleshooting
- IP and DNS verification
- System performance monitoring
- Process management
- Disk space analysis
- Linux permissions and access control
- Basic security verification
- Technical incident documentation

- Project PDF

### Project Outcome
The project provided practical experience in investigating and documenting common IT support incidents using structured troubleshooting, system checks, configuration verification, and basic Linux administration.
